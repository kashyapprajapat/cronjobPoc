⚡ Execution Lifecycle
How each cron job fires and results appear in the live dashboard.
01
🚀
Server Starts
Express starts on port 3000. node-cron schedules 8 enabled jobs with cron expressions (every 6–22 seconds in demo mode).
02
⏰
Cron Fires
node-cron triggers the job callback at the scheduled interval. The server picks 2–3 random log messages simulating real work.
03
📡
SSE Broadcast
The execution result is broadcast to ALL connected browsers via Server-Sent Events (SSE) on the /events endpoint.
04
🖥️
Live Terminal
The browser receives the SSE event, appends it to the terminal feed with job icon, name, duration, and timestamped log lines.
05
💡
Card Pulse
The matching job card briefly glows green to indicate it just executed. The run counter increments in real-time.
06
🔔
Toast Alert
A slide-in toast notification appears showing the job name and execution duration, then auto-dismisses after 3.5 seconds.

🔌 API Reference
REST endpoints exposed by the Express server.
GET / Serves the live dashboard HTML page
GET /events SSE stream — real-time execution push
Returns a text/event-stream connection. Events: execution (job fired), toggle (job enabled/disabled), stats (counter update).
GET /api/jobs List all 10 jobs with current state 
// Response
[
  {
    "id": 1,
    "name": "daily-report-generator",
    "enabled": true,
    "runCount": 42,
    "lastRun": "2024-12-01T10:30:00Z"
  }
]
POST /api/jobs/:id/toggle Enable or disable a specific job
Toggles the job's enabled state. If enabling, node-cron starts the task. If disabling, it stops. Broadcasts SSE event to all connected browsers. 
// Response
{
  "success": true,
  "jobId": 9,
  "enabled": true
}
GET /api/history Last 50 execution records
GET /api/stats Aggregate stats (enabled, disabled, total runs)
GET /docs This documentation page
